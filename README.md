# Halo VPN

Десктопный клиент для Windows и Linux на ядре [mihomo](https://github.com/MetaCubeX/mihomo) (Clash Meta). Electron + React + framer-motion.

Главное:

- Три режима:
  - **Только заблокированное** (по умолчанию) — через VPN только сайты из списков блокировок РФ (реестр РКН, сервисы с геоблоком), всё остальное напрямую с вашим обычным IP. Категории — галочками на экране «Правила».
  - **Всё, кроме РФ** — через VPN всё, кроме российских сайтов (заблокированные `.ru` всё равно идут через VPN).
  - **Весь трафик** — всё через VPN.
- Уживается с другим клиентом рядом (например, Clash Verge): если чужой TUN перехватывает трафик, Halo выпускает свой трафик прямо через сетевую карту, а системный прокси, пока Halo подключён, возвращает на себя.
- **Раздельное туннелирование по приложениям**: каждой программе — VPN / по правилам / напрямую. Программы — из установленных, запущенных или выбором .exe.
- Подписки: Clash YAML, sing-box JSON, base64/обычный список ссылок `vless://`, `vmess://`, `trojan://`, `ss://`, `hy2://`, `tuic://`. Остаток трафика и срок берутся из заголовка `subscription-userinfo`.
- Запуск: «Запускать вместе с Windows», «Подключаться при запуске», «Запускать свёрнутым в трей» — с тремя галочками Halo после входа в Windows сам стартует в трее и включает VPN.
- Группы «Авто · лучший» (url-test, перепроверка задержки каждые 2 минуты) и ручной выбор узла, проверка задержки, соединения, график трафика, проверка доступности сервисов, тест скорости, меню в трее.

## Запуск

```bash
npm install
node node_modules/electron/install.js   # если npm не скачал Electron (npm 11 не запускает install-скрипты)
npm run dev                              # Vite + Electron с горячей перезагрузкой
```

Сборка и запуск собранной версии:

```bash
npm run build
npm start
```

Установщик Windows (NSIS) в папку `release/`:

```bash
npm run dist
```

Ядро лежит в `resources/core/mihomo.exe` (v1.19.32, с официальных релизов MetaCubeX). Обновить — заменить файл (и нажать «Переустановить» у службы, если она установлена).

## Служба Halo (TUN без прав администратора)

TUN-режиму нужны права администратора. Чтобы не запускать весь Halo от администратора, есть служба-помощник **Halo Service** — по аналогии с `clash-verge-service` в Clash Verge Rev:

- **Настройки → Сеть → Служба Halo → «Установить службу»**. Windows один раз спросит разрешение (UAC). Служба копируется вместе с ядром в `C:\Program Files\Halo Service\` (писать туда может только администратор) и регистрируется как служба Windows `HaloService` с автозапуском от имени SYSTEM.
- Дальше Halo, запущенный обычным образом, при подключении просит службу запустить ядро — TUN и правила по приложениям работают без админского перезапуска. Если службы нет, ядро запускается как раньше, дочерним процессом.
- Связь — именованный канал `\\.\pipe\halo-service`, строка JSON на запрос и на ответ (`start` / `stop` / `status`). Каждый запрос подписан секретом из файла `service.key` в папке данных Halo (`%APPDATA%`). Служба запускает только своё `mihomo.exe` и принимает лишь пути к `.yaml`-конфигу и рабочей папке.
- Если Halo закрылся аварийно, служба сама останавливает ядро (следит за процессом клиента), чтобы TUN не остался висеть.
- Удалить — кнопкой «Удалить» там же; деинсталлятор Halo тоже удаляет службу (спросит UAC).

Служба написана на C# (`service/HaloService.cs`) и собирается компилятором `csc.exe` из .NET Framework 4, который уже есть в Windows 10/11, — Rust и .NET SDK не нужны. `npm run build` пересобирает её в `resources/service/halo-service.exe`, если исходник новее. Для отладки её можно запустить в консоли: `halo-service.exe run <файл-секрета> <mihomo.exe>`.

## Как устроено

| Файл | Что делает |
| --- | --- |
| `electron/main.cjs` | Окно, трей, IPC, подключение/отключение, проверки |
| `electron/config.cjs` | Сборка конфига mihomo: режимы, категории, правила приложений, DNS |
| `electron/subscription.cjs` | Загрузка и разбор подписок |
| `electron/core.cjs` | Запуск ядра (сам или через службу), REST API, поток трафика |
| `electron/service.cjs` | Клиент службы Halo Service: установка/удаление через UAC, команды по каналу |
| `service/HaloService.cs` | Сама служба: запускает mihomo с правами SYSTEM |
| `build/installer.nsh` | Удаление службы при деинсталляции |
| `electron/system.cjs` | Системный прокси (реестр), права администратора, список процессов |
| `src/` | Интерфейс: `screens/` — экраны, `components/` — каркас и элементы |

Списки блокировок — гео-базы [runetfreedom/russia-v2ray-rules-dat](https://github.com/runetfreedom/russia-v2ray-rules-dat) (категории `ru-blocked`, `ru-available-only-inside`), ядро само обновляет их раз в сутки.

## Разработка

- `npm run snap` — собрать интерфейс, открыть настоящее окно Electron, пройти по всем экранам и сохранить скриншоты в `.shots/electron/`.
- `npm test` — тесты парсера подписок, сборщика конфига и службы (включая запуск настоящего mihomo через `halo-service.exe run`, без TUN и без прав администратора).
- `npx vite` и открыть `http://localhost:5173` — интерфейс в браузере на демо-данных (без Electron). `#apps`, `#rules` и т. д. открывают нужный экран, `?static` выключает анимации.
